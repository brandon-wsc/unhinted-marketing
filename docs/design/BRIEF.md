# Unhinted — Visual brief

> **Status:** Docs-only — positioning locked for discussion; **CSS tokens not applied yet.**

## Positioning

**Reliable tools that harness unhinged creative energy.**  
Product name stays **Unhinted**. “Unhinged” describes the copy kid / craft, not the company wordmark.

| Layer | Job |
|-------|-----|
| **Shell** | Tech-product standard (shadcn structure): scannable desk — header, history, composer, preview, Confirm |
| **Craft** | Chat 小編 + agent action trail — spitball copy, special icons, temp loading filler (“幫緊你…”) |

Asymmetric “half unhinged, half reliable”: **reliable holds the reins** (area + default tone). Madness only where a person/agent is speaking.

Login / shell: orderly chrome; at most a **corner** of craft signal — never half the viewport unhinged.

## Anti-slop

No indigo/purple SaaS default as brand, no cream+terracotta serif kit, no broadsheet, no neon/Liquid Glass shell, no glow stacks.

## Shell reference

Structure ≈ shadcn / big-tech product UI. Proposed brand difference = **ink primary + IBM Plex / Noto Sans HK + voice accent** (see TOKENS) — apply in a later code pass.
